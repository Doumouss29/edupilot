Installer EduPilot

Accédez à votre établissement, vos cours, notes et notifications depuis l'écran d'accueil de votre téléphone.

Installation sur iPhone
1. Ouvrez cette page dans Safari si vous venez de WhatsApp.
2. Appuyez sur le bouton ci-dessous pour afficher l’application EduPilot.
3. Sur cette page EduPilot, appuyez sur Partager → Sur l’écran d’accueil → Ajouter.
Important : n’ajoutez pas cette page d’explication à votre écran d’accueil.
Ouvrir EduPilot pour l’installer →

L’icône créée sera celle d’EduPilot et l’application démarrera dans son propre espace.

Sur Android (Chrome)
Ouvrez le menu ⋮ puis appuyez sur Installer l’application ou Ajouter à l’écran d’accueil.

EduPilot semble déjà ouvert en mode application.

Se connecter à EduPilot

Après installation et connexion, ouvrez la cloche 🔔 pour activer les notifications. L'autorisation vous sera demandée uniquement si vous choisissez de les activer.
