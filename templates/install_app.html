Installer EduPilot

Accédez à votre établissement, vos cours, notes et notifications depuis l'écran d'accueil de votre téléphone.

Sur iPhone (Safari)
1. Appuyez sur le bouton Partager de Safari.
2. Choisissez Sur l’écran d’accueil (ou « Ajouter à l’écran d’accueil »).
3. Confirmez avec Ajouter.

Si vous utilisez un autre navigateur, ouvrez d'abord ce lien dans Safari.

Sur Android (Chrome)
Ouvrez le menu ⋮ puis appuyez sur Installer l’application ou Ajouter à l’écran d’accueil.

EduPilot semble déjà ouvert en mode application.

Se connecter à EduPilot

Après installation et connexion, ouvrez la cloche 🔔 pour activer les notifications. L'autorisation vous sera demandée uniquement si vous choisissez de les activer.
